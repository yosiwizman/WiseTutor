# State — Current Milestone

**Purpose:** Name the single milestone the team is currently driving toward. One milestone at a time. If two things are in play, one is the milestone and the other is a distraction.

**Rules:**
- Only one milestone is "current." Multiple in-flight ≠ multiple milestones; re-sequence.
- A milestone has a measurable acceptance criterion — not "improve X".
- If the milestone has not moved in 2 weeks, it is mis-sized; split or re-scope.
- When a milestone completes, it moves to `.cto/03_state/completed_milestones.md` (created on first completion), and a new one is named here.
