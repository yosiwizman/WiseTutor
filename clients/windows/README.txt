WiseTutor runs on Mr W's ai-desktop computer at home.
This launcher just opens the app in your browser.

Step 1: Unzip this folder to your Desktop.

Step 2: Right-click install-wisetutor.ps1 -> "Run with PowerShell".

Step 3: If Windows says the script is blocked, right-click it -> Properties ->
        "Unblock" -> OK, then try again.

Step 4: Double-click the new WiseTutor icon on your Desktop.
        It opens in Chrome like a regular app window.

Troubleshooting:
  If nothing happens, make sure ai-desktop is on and that you are on the
  home Wi-Fi.
